# Annual Report Forensic Analyst

[English](README.md) | 中文

版本：v2.1.2 · Apache License 2.0

## 项目概览

Annual Report Forensic Analyst 不是财报摘要工具、自动研报工具或股票推荐工具，而是一个基于证据的企业研究分析框架。

它用于重建企业如何创造价值，并检验管理层叙事是否得到公开披露证据的支持。核心分析链条是：

```text
企业年报
    ↓
证据提取
    ↓
商业模式重建
    ↓
管理层叙事验证
    ↓
财务现实分析
    ↓
资本配置审查
    ↓
未来验证变量
```

本项目不提供投资建议、买入/卖出建议、股票评级、目标价、估值意见或缺乏证据支持的财务预测。

## 研究流程

```text
企业年报
    ↓
Annual Report Forensic Analyst
    ↓
财报取证研究输出
    ↓
交付层
    ↓
PDF 报告 / 高管汇报幻灯片 / 内部简报
```

核心 Skill 负责生成研究分析；PDF 和幻灯片属于独立的输出流程，用于将完成的研究转换为交付格式。

## 输出层（Output Layer）

Annual Report Forensic Analyst 核心 Skill 负责生成结构化研究分析，不直接生成最终交付文件。

```text
企业年报
    ↓
财报取证分析
    ↓
结构化研究结果
    ↓
输出层
    ↓
PDF 报告 / 高管汇报 / 内部简报
```

输出层负责将完成的研究转换为不同的沟通格式。

## 可用的输出提示词

可复用的输出提示词位于 `prompts/` 目录。

### PDF报告生成提示词

文件：[prompts/pdf-report-generation-prompt_CN.md](prompts/pdf-report-generation-prompt_CN.md)

用途：将完成的财报取证分析转换为专业研究报告。

适用场景：

- 管理层报告
- 企业研究材料
- 内部决策文件

输出结构：执行摘要、商业模式、管理层叙事、证据审查、财务现实、资本配置、关键风险、监测仪表板。

要求：保留事实/推断/分析师观点，保留证据链，不新增未经支持的判断，不加入估值意见。

### 高管汇报幻灯片生成提示词

文件：[prompts/executive-slide-generation-prompt_CN.md](prompts/executive-slide-generation-prompt_CN.md)

用途：将研究结论转换为高管沟通材料。

适用场景：CFO 汇报、CEO 演示、董事会讨论和战略复盘。

强调：幻灯片不是文字摘要，而是将研究判断转化为核心信息、证据关系和管理层决策语言。

## 重要设计原则

PDF 和幻灯片与核心财报取证引擎保持分离，因为研究质量不应受到展示格式的限制。

```text
研究引擎
    ↓
结构化分析
    ↓
输出提示词
    ↓
PDF / 幻灯片 / 内部简报
```

## 分析原则

每一项结论都必须区分：

- 事实（Fact）：来源材料直接披露的信息；
- 推断（Inference）：基于披露事实形成的合理解释；
- 分析师观点（Analyst View）：说明依据和局限性的独立判断。

管理层表述应被视为待验证的假设，而不是直接复述的结论。

## 分析模式

- 单年度财报取证模式：分析一份年度报告；
- 多年度财报取证模式：解释多个年度之间商业模式、管理层叙事、财务表现和资本配置的变化；
- 高管汇报支持：为后续幻灯片生成提供结构化研究输入。

## 快速开始

示例：使用 SAP 2023、2024、2025 年度报告，运行多年度财报取证模式。

```text
请使用 Annual Report Forensic Analyst v2.1.1 分析以下年度报告。

公司：SAP
模式：多年度财报取证模式
报告：2023 年度报告、2024 年度报告、2025 年度报告

重点分析：
1. 商业模式重建
2. 价值创造逻辑
3. 管理层叙事演变
4. 支持管理层主张的证据
5. 挑战管理层主张的证据
6. 财务现实
7. 资本配置
8. 未来成功假设

每项结论都区分：事实、推断、分析师观点。
不要提供投资建议、目标价、股票评级或缺乏证据支持的预测。
```

请以文件或清晰标识的来源材料提供年度报告。运行多年度模式时，应说明缺失年度、重述、币种变化和合并范围变化等限制。

## 安装与使用

Codex 用户请从 Releases 下载 Codex Skill 安装包，并参阅 [INSTALLATION.md](INSTALLATION.md)。开发者可以克隆本仓库，查看 framework、workflows、prompts、examples 和 tests。

Skill 安装后：

1. 准备一份或多份年度报告；
2. 选择单年度或多年度财报取证模式；
3. 使用财报取证分析提示词模板；
4. 检查证据、不确定性以及事实/推断/分析师观点的分离；
5. 研究完成后，再单独使用 PDF 报告或高管幻灯片提示词。

## 仓库结构

- `framework/`：核心方法论与分析原则
- `workflows/`：可重复执行的研究流程
- `prompts/`：分析提示词和输出层提示词模板
- `examples/`：公开示例说明
- `tests/`：验证记录
- `docs/`：仓库与架构文档

## 局限性

本项目是研究与推理框架，不构成投资建议。不提供投资推荐、买入/卖出建议、股票评级、目标价、估值意见、财务预测，也不对超出证据范围的结论作确定性承诺。
