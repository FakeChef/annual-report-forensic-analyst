# Code of Conduct

This project follows the core principles of the Contributor Covenant and GitHub Community Standards. We maintain a professional, inclusive, good-faith, and evidence-based community.

## Community Principles

- Respect contributors with different backgrounds, experiences, and viewpoints.
- Participate in good faith and address issues and evidence rather than individuals.
- Distinguish clearly between facts, inferences, and opinions, and acknowledge uncertainty.
- Avoid unsupported claims, personal attacks, harassment, discriminatory language, and other inappropriate conduct.
- Keep disagreements constructive and help the community improve research quality.

## GitHub Community Standards

All Issues, Pull Requests, discussions, and other community interactions must follow GitHub Community Standards. Maintainers may address violations of this code and restrict participation when necessary.

If you experience or observe a violation, contact the maintainers through the project support channels or GitHub private communication, providing relevant context where possible.
