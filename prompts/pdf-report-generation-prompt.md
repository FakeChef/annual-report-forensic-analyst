# PDF Report Generation Prompt

This prompt is NOT part of the core forensic engine. It converts completed forensic research into a professional report for management, research professionals, and analysts.

Using the supplied completed research, create a report with:

1. Executive Summary
2. Business Model
3. Management Narrative
4. Evidence Review
5. Financial Reality
6. Capital Allocation
7. Risks
8. Monitoring Dashboard

Preserve every Fact / Inference / Analyst View distinction. Do not add unsupported conclusions, investment advice, valuation opinions, target prices, ratings, or forecasts. Retain source references and state limitations. Use clear headings, tables, and concise evidence-led prose suitable for PDF export.
