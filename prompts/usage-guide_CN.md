# 提示词使用指南

1. 安装 Codex Skill。
2. 准备一份或多份年度报告，并记录公司、分析期间和行业重点。
3. 使用 `forensic-analysis-prompt_CN.md`，选择单年度或多年度财报取证模式。
4. 检查证据、来源、不确定性以及事实/推断/分析师观点的分离。
5. 研究完成后，单独使用 `pdf-report-generation-prompt_CN.md` 或 `executive-slide-generation-prompt_CN.md`。

架构关系：Core Skill 是研究引擎，本提示词库属于输出层。输出提示词不得改变或绕过核心研究规则。
