# Annual Report Forensic Analyst v2.1.1 Release Notes

## Overview

This is the first public release of Annual Report Forensic Analyst.

The project provides a structured framework for forensic analysis of annual reports.

## Highlights

- Multi-Year Forensic Mode
- Single-Year Forensic Mode
- Executive Slide Mode
- Fact / Inference / Analyst View separation
- Management narrative testing
- Capital allocation review framework

## Packages

This release provides two packages:

### Codex Skill Install Package

For users who want to install the skill into Codex.

### GitHub Repository Package

For researchers and developers who want to study, extend and contribute.

## Limitations

This framework does not provide:

- investment recommendations
- stock ratings
- target prices
- unsupported forecasts

## Next

Future releases will be driven by real-world research usage and community feedback.
