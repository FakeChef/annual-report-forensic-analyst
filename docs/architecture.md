# Architecture

The repository separates research reasoning from delivery formatting:

```text
Core Engine
    ↓
Research Output
    ↓
Delivery Layer
```

## Core Engine

The Codex Skill and repository methodology generate evidence-based forensic research. They preserve Fact / Inference / Analyst View and the project's analytical restrictions.

## Research Output

The output is a structured analysis of the business model, management narrative, evidence, financial reality, capital allocation, risks, and future success assumptions.

## Delivery Layer

The Delivery Layer is separate from the core engine. It includes:

- PDF reports
- Executive slides
- Internal briefings

The prompt library documents these output processes without changing the research engine.
