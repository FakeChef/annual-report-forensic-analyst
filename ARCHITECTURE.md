# Architecture

## Design Philosophy

Separate runtime execution from research knowledge.

## Layers

### Layer 1: Codex Runtime

SKILL.md

Purpose:
- registration
- execution rules
- constraints

### Layer 2: Research Framework

framework/

Purpose:
- methodology
- analytical principles

### Layer 3: Workflow Layer

workflows/

Purpose:
- repeatable research processes

### Layer 4: Evidence Layer

examples and tests

Purpose:
- validation
- learning
- improvement
