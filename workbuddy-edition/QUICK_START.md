# Quick Start — 5 Minutes

Use this sequence for a first run. **Research first, output second.**

```text
Install
  ↓
Upload Annual Report
  ↓
Select Research Mode
  ↓
Run Analysis
  ↓
Generate Output Layer
```

## 1. Install

Install the WorkBuddy package and open the skill from the Skills area.

## 2. Upload Annual Report

Attach one annual report for Single Year Forensic Mode, or two or more comparable reports for Multi Year Forensic Mode. State the company, period, and optional industry focus.

## 3. Select Research Mode

Choose **Single Year Forensic Mode** or **Multi Year Forensic Mode**. The research mode produces the evidence-led analysis.

## 4. Run Analysis

Ask WorkBuddy to reconstruct the business model, test management claims, identify supporting and contradicting evidence, and separate conclusions into Fact, Inference, and Analyst View. Review sources, limitations, and uncertainty.

## 5. Generate Output Layer

Only after research is complete, request one output conversion:

- PDF research report
- Executive slide brief
- Enterprise infographic brief

These outputs are delivery formats, not new research. Human-review the result before formal or external use.

## Copyable first prompt

```text
Use Annual Report Forensic Analyst — WorkBuddy Edition.
I have uploaded {{Company}} annual report(s) for {{Period}}.
Run {{Single Year Forensic Mode or Multi Year Forensic Mode}} first. Analyze the reports as evidence, separate every material conclusion into Fact, Inference, and Analyst View, and show sources, contradictions, limitations, and open questions. Do not generate an output deliverable until the research is complete. This is enterprise research and management decision support, not investment advice.
```
