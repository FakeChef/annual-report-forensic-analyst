# Marketplace 中文描述

## 长描述

Annual Report Forensic Analyst 是一个基于证据的企业研究与管理层洞察框架。上传一份或多份年报，即可重建商业模式，验证管理层主张，解释跨年度变化，并识别不确定性和待调查问题。

适用于 CFO 年度经营复盘、竞争分析、管理层汇报准备；也适用于战略团队分析商业模式变化和竞争格局，以及咨询顾问准备客户研究底稿和汇报材料。普通用户只需上传年报，即可开始企业研究。

支持单年度和多年度研究，并可将已完成研究转换为 PDF 研究报告、Executive Slide brief 或企业研究信息图 brief。这些属于输出转换层，正式或对外使用前需要人工复核。

这里的 Forensic Analysis 指证据验证方法，不是法律调查。Fact / Inference / Analyst View 分别表示披露事实、合理推断和独立判断。本 Skill 不提供投资建议、估值、评级、目标价或法律调查结论。

## 建议触发词

年报研究、三年年报分析、CFO 汇报、年度经营复盘、商业模式变化、竞争格局、咨询研究底稿、PDF 研究报告、Executive Slides、企业研究信息图。

## 输入

上传一份或多份年报，并提供公司、期间、可选行业重点、受众和期望输出。
